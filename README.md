# CityDrivingTraining

Офлайн 3D-тренажёр вождения для автошкол: парковочная площадка, городской маршрут по данным OpenStreetMap, конструктор собственных упражнений, объяснимая оценка по таблице правил, покадровый реплей, статистика учеников и кабинет инструктора.

> **Важно (статус продукта):** это **учебная симуляция**. Она **не является официальным экзаменом ГИБДД** и не заменяет занятия с инструктором. Встроенный профиль оценки (`ru-demo-0.2.0`) и размеры парковочных боксов имеют статус **`unvalidated`** (предварительные) до проведения сверки и подписи инструктора (см. [`docs/CALIBRATION_GUIDE.md`](./docs/CALIBRATION_GUIDE.md)).

---

## Ключевые свойства

- **Полный офлайн:** собирается в единственный самодостаточный файл `dist/index.html` (`vite-plugin-singlefile`), 0 внешних CDN и 0 сетевых запросов во время занятий.
- **Приватность по умолчанию:** нет сервера и аккаунтов — попытки, ФИО учеников, настройки и оценки инструкторов хранятся локально в браузере школы (`IndexedDB` + `localStorage`), выгружаются и удаляются одной кнопкой.
- **Детерминированное ядро (`1/60 с`):** одинаковый ввод даёт побитно одинаковую траекторию при 30 и 144 FPS, в браузере и в чистом Node.js — реплей, контрольные суммы `cdt.golden.v1` и 33 автотеста работают без браузера.
- **Интерактивный редактор карт и офлайн-импорт OSM:** загрузка локальных `.osm` XML (экспорт с openstreetmap.org / JOSM), Overpass `.json` и `.geojson`, размещение и перетаскивание 12 классов дорожных знаков, светофоров, переходов, дорог, парковочных боксов и 8 классов препятствий с сеткой, поворотом и `Ctrl+Z`.
- **Честная геометрия автомобиля:** Kia Ceed JD (кат. B, база `2,65 м`, колея `1,57 м`, габариты `4,31 × 1,80 м`), геометрия Аккермана, руль `±540°`, настраиваемый выворот внутреннего колеса `33–42°` (базовый `35°`), АКПП `P / R / N / D`, холодный старт, 3 независимых зеркала.
- **Устройства ввода:** клавиатура, мышь, раздельные мультитач-педали, экранный руль и пошаговая калибровка USB-руля / педалей / геймпада (Gamepad API).

## Быстрый старт

Требуется **Node.js 20+** (в CI используется Node.js 22) и **npm**.

```bash
npm ci                 # установка зависимостей по package-lock.json
npm run dev            # режим разработки
npm run build          # сборка автономного dist/index.html (можно переносить на флешке)
```

### Проверка качества (обязательный гейт)

```bash
npx tsc --noEmit                          # проверка типов TypeScript
npm run build                             # прод-сборка single-file бандла
node scripts/run-tests.mjs --check-dist   # чистота ядра + 33 автотеста + паспорта @module + сверка доков + офлайн-бандл
```

Для запуска браузерного смоука (`tests/browser-smoke.mjs`, сценарии `A–P`, Playwright + Chromium) см. команды в [`HANDOFF.md`](./HANDOFF.md) (раздел 2).

### Сборка и импорт офлайн-карт OpenStreetMap

```bash
node tools/build-map-pack.mjs <raw-overpass.json> <out-pack.json> [допускМетров=0.8]
```

Локальные файлы `.osm` XML, Overpass `.json` и `.geojson` также загружаются напрямую без интернета во вкладках **«Свой сценарий»** (с редактированием) и **«3D-Тренажёр»**.

### Каналы публикации GitHub Pages (`.github/workflows/deploy.yml`)

Однофайловый `dist/index.html` автоматически выкладывается в ветку `gh-pages` с разделением по веткам:
- `main` → корень сайта (`https://froloved.github.io/DrvrTestingVersion/`, с сохранением подпапок);
- `Arena_v1` → промежуточная сборка v1 (`https://froloved.github.io/DrvrTestingVersion/v1/`);
- `arena/**` → тестовая сборка Arena (`https://froloved.github.io/DrvrTestingVersion/arena/`);
- `GemCommits` → превью-канал (`https://froloved.github.io/DrvrTestingVersion/preview/`).

## Вкладки приложения

| Вкладка | Назначение |
|---|---|
| **3D-Тренажёр** | Упражнения «Бокс 90°», «Параллельная парковка», «Город (OSM)» и «Свой сценарий»; перемещаемые панели HUD, 3 зеркала, калибровка выворота и USB-руля. |
| **Свой сценарий** | Интерактивный 2D-редактор карт: офлайн-импорт `.osm` XML, Overpass JSON, GeoJSON и JSON, 12 классов дорожных знаков, светофоры, переходы, дороги, боксы и 8 классов препятствий, перетаскивание, поворот, сетка и `Ctrl+Z`. |
| **Разбор и Реплей** | Протокол ошибок с пояснениями, 2D-реплей с проверкой детерминизма, слепая оценка инструктора, журнал до 300 попыток, выгрузка `cdt.golden.v1`. |
| **Статистика** | Успеваемость по ученикам и упражнениям, частые нарушения, доля согласия с инструкторами (95 % ДИ Уилсона), выгрузка CSV для Excel, сводного Markdown-отчёта и JSON. |
| **Инструктор и Правила** | Редактор штрафных баллов, размеров боксов, подписи правил (`unvalidated` / `instructor_signed`), резервная копия `cdt.backup.v1`, правовой блок и очистка данных. |
| **Тесты и Модули** | Прогон 34 автотестов ядра в браузере, карта модулей, копирование/скачивание `HANDOFF.md`, заготовки CI и Tauri. |
| **План и стратегия** | Дорожная карта, принципы, приоритеты, журнал решений, экспорт `strategy.md` и архивный технический аудит. |

## Управление по умолчанию (в 3D-тренажёре)

| Действие | Клавиши / мышь |
|---|---|
| Запуск двигателя / ручник / ремень / фары | `I` · `Space` · `B` · `L` |
| Селектор 6-ст. КПП (`P` / `R` / `N` / `D1–D6`) | `P` · `R` · `N` · `F` |
| Секвентальное переключение КПП (`M1–M6`) | `Shift` (вверх ▲) · `Right Shift` / `X` (вниз ▼) |
| Газ / тормоз / руль | `W` · `S` · `A` (влево) / `D` (вправо) |
| Поворотники (левый / правый / аварийка) | `Q` · `E` · `Z` |
| Руль мышью / орбита камеры / зум | `ЛКМ` по сцене · `ПКМ` по сцене · колесо мыши |
| Смена камеры / скрыть HUD (зеркала остаются) | `C` · `H` |
