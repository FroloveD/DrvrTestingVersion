## 2. На чём остановились

**Текущая рабочая ветка:** `arena/exam-routes` (создана от `Arena_v1`). Предыдущие записи ниже описывают историю исходной ветки и сохранены как контекст, а не как инструкции для текущего направления.

**Последняя задача:** исправлена метрическая сетка 2D-карты по реализации из `arena/95028c9f-drvrtestingversion` (исходный фикс `0f176b3`). Отрисовка теперь зависит от выбранного шага привязки: «Выкл» скрывает сетку, `0,5 / 1 / 2 / 5 м` меняют её шаг; при сильном отдалении линии автоматически прореживаются кратно шагу, выделяются главные деления и оси `0,0`. Добавлены тестовые селекторы и браузерная проверка O1b. Исправление перенесено точечно — без слияния остальных изменений соседней ветки.

**Следующий шаг:** дождаться CI и проверить в браузере переключатели «СЕТКА» на обычном масштабе и на большой OSM-карте; затем повторно проверить зум колёсиком и отсутствие прокрутки страницы.

**Следующий шаг:** спроектировать совместимую модель каталога маршрутов (метаданные, траектория, манёвры, контрольные точки, источник и статус ручной проверки), затем добавить GitHub-каталог и локальный импорт без вмешательства в физику и механику симуляции.

**Публикация:** `arena/exam-routes` развёртывается отдельно в `/exam-routes/`; остальные ветки `arena/*` продолжают использовать общий `/arena/`. Это отдельный URL/каталог внутри Pages-сайта репозитория, а не отдельный GitHub Pages site.

**Текущая точка:** по задаче импорта и редактора карт реализован полный офлайн-контур (чистое ядро + 2D-редактор + 3D-рендер + тесты + документация):
- **Офлайн-импорт карт (`src/maps/osmXml.ts`, `src/maps/osmLoader.ts`, `src/scenarios/custom.ts`):** поддержка `.osm` XML (экспорт с openstreetmap.org / JOSM без `DOMParser`), Overpass `.json`, `.geojson`, JSON сценариев, резервных копий `cdt.backup.v1` и клонирования встроенных миров (включая «Город OSM») с сохранением атрибуции ODbL 1.0 (`mapMeta`); распознавание дорог, зданий, заборов/бордюров, деревьев, опор, островков, светофоров, зебр и дорожных знаков.
- **Каталог классов (`src/scenarios/signs.ts`, `src/sim/types.ts`):** 12 классов дорожных знаков (`3.24` скорость, `2.5` STOP, `2.4` Уступите дорогу, `2.1` Главная дорога, `5.19` Пешеходный переход, `3.27` Остановка запрещена, `3.1` Въезд запрещён, `6.4` Парковка P, `4.1.1/4.1.2/4.1.3` направления, `5.21` Жилая зона 20 км/ч), 8 классов препятствий (`curb`, `cone`, `pole`, `fence`, `tree`, `island`, `building`, `parked_car`), светофоры со стоп-линиями, пешеходные переходы, ломаные дороги с узлами, парковочные боксы и КТ маршрута.
- **Симуляция и 3D (`src/sim/step.ts`, `src/render/roadSignTextures.ts`, `src/render/sceneController.ts`, `src/components/DebriefView.tsx`):** скоростные знаки задают направленные отрезки ограничения, обрываемые на первом пересечении с поперечной дорогой), КТ с `requireStop` требуют полной остановки, `rules.ts` не изменялся (`unvalidated` сохранён); процедурные 3D-знаки (ориентированные к потоку, с оборотной стороной), 3D-ограждения, деревья, островки и отображение на 2D-карте разбора.
- **Интерактивный 2D-редактор (`src/components/MapCanvasEditor.tsx`, `src/components/CustomScenarioView.tsx`, `src/scenarios/editorOps.ts`):** палитра классов, добавление кликом, перетаскивание мышью/тачем (включая узлы дорог, стоп-линии и центры скоростных зон), ручка поворота, зум колесом/кнопками, панорама, привязка к сетке (`0,5 / 1 / 2 м`), фильтры слоёв, дублирование (`Ctrl+D`), удаление (`Del`), `Undo/Redo` (`Ctrl+Z` / `Ctrl+Y`), автомаршрут по дорогам, подгонка границ и инспектор свойств.
- **Тесты, CI и GitHub Pages:** добавлены автотесты `T27–T29` (`29/29`), браузерный смоук `O` (`tests/browser-smoke.mjs`), `ADR-013`, синхронизированы `HANDOFF.md`, `README.md`, `docs/ARCHITECTURE.md`; в `.github/workflows/deploy.yml` настроена многоканальная публикация в `gh-pages` (`main` → корень с `keep_files: true`, `Arena_v1` → `/v1/`, `arena/exam-routes` → `/exam-routes/`, остальные `arena/**` → `/arena/`, `GemCommits` → `/preview/`).

## 5. Правило обновления

После каждой задачи в этой ветке `arena/exam-routes`:
1. Обновить разделы **1** (состояние и дата), **2** (на чём остановились + запись в историю), **3** (что дальше) и **4** (новые/закрытые `TD-*`).
2. При изменении модулей, инвариантов, числа тестов или ключей хранилища обновить `src/handoff.ts` и выполнить `node scripts/write-handoff.mjs`.
3. Пройти обязательный гейт (`npx tsc --noEmit && npm run build && node scripts/run-tests.mjs --check-dist`).
4. Закоммитить и запушить изменения в `origin/arena/exam-routes`, чтобы состояние этой рабочей ветки сразу читалось на GitHub.
