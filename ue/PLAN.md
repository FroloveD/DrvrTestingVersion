# План UEDev: клавиатура и мышь

## Границы

UEDev — отдельный нативный эксперимент, не замена рабочей Arena_v1. На первом этапе нет руля/педалей, Force Feedback, VR, большого города, живого трафика и изменений правил оценки.

## Стартовый экран и пауза (исходники добавлены, UE-запуск не проверен)

- Menu: выбор тестового заезда, отдельные разделы маршрутов/автомобиля/настроек/журнала. Пока без редактора и сохранения.
- Driving: нет верхнего меню, только диагностический HUD.
- Esc: пауза → продолжить / холодный перезапуск / итог / меню без сохранения.
- Summary: технический итог без оценки, новый заезд или меню.
- Состояния проверяются переносимыми тестами; фокус, ввод и Slate — ручным smoke в Standalone.
- Всё работает внутри одной карты; полноценную загрузку добавим с реальными маршрутами.

## Ближайшая сессия

1. Пересобрать обновлённый UEDevEditor на подтверждённом UE 5.7.4/Windows 11.
2. Проверить изменяемый газ Ctrl+колесо, D1–D6, RPM/переключения, ручные передачи и тормоз.
3. Проверить столкновения и паузу после обновления; собрать субъективную обратную связь.
4. Далее — боковая динамика/руление, салон и импорт маршрутов отдельными шагами.

## Принципы

- Нет обещания прироста FPS без проверки на одной машине; не сравнивать редактор UE с релизным вебом.
- Базовое ядро SI: x влево, z вперёд, heading положительный влево. Адаптер UE: X=z×100, Y=−x×100, yaw=−heading.
- UE не входит в веб-бандл. Существующие тесты и формат заездов не меняются.
- По умолчанию без Lumen и motion blur; картинку наращивать после работоспособного среза.
- Ассеты в текущем каркасе только engine primitives. Перед добавлением .uasset/.umap согласовать Git LFS и лицензии; SDK, Marketplace-паки и бинарные сборки не коммитить.
